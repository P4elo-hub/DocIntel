# write_integration — integration-standard-kit

Раздел **4.x** — REST/gRPC/GraphQL/SOAP или асинхронное событие (Kafka).

Источник контракта — **search_context (KB + контракты из диалога)**, не заглушки скелета.

Правила:
- Если в брифе/диалоге несколько обменов — опиши **каждый** отдельным подразделом
  (несколько блоков `#### 4.1.1. …` / сервисов), а не один урезанный.
- Таблицы полей и JSON-примеры копируй **целиком** из KB/диалога
  (все ключи верхнего уровня и вложенность). Новое поле из брифа — единственное добавление.
- Запрещены короткие stub вроде `{ "operations": [ ... ] }` вместо реального ответа
  (generalStatus, totalDeals, commissions, даты и т.п. — если они есть в KB/диалоге).
- Запрещены учебные `param1` / `result`+`status`+`timestamp`.
