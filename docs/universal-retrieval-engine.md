# Универсальный retrieval-движок (заметки)

Черновик направления: меньше доменных if’ов (налог / вармаржа / Linked Events),
больше общего индекса и retrieve. Записано после починки reranker’а в Docker
и разбора отличий DocIntel vs m5_b6.

## 1. Чанкинг по структуре файла

Резать мега-`##` не только по ~1024 токена, а по `###`, JSON-блокам, таблицам,
типам операций. Иначе реранкеру приходится вытаскивать нужный фрагмент
(например налог) из каши ранних `transaction_buy` в одном огромном разделе.

## 2. Метаданные при ingest

Из пути и заголовков проставлять поля вроде `layer=fe|be`, `screen=detail|feed|…`,
`doc_type`, ticket. Boost/filter по метаданным, а не regex «композит / лента / tax»
в рантайме.

## 3. Query → слоты (LLM / лёгкий classifier)

Свободные поля: сущность, экран, тип операции, API-id — без жёсткого словаря SIHIST.
Дальше: filter + dense + rerank.

## 4. Hybrid (BM25 + dense) + живой rerank

Нужен для редких имён обменов и полей. Зависимости: `qdrant-client>=1.16` +
`llama-index-vector-stores-qdrant>=0.10`, флаг `RAG_USE_HYBRID=true`, затем
full reindex (sparse BM25 в коллекции). Reranker — отдельно (том `hf_cache` +
entrypoint с `chown`).

## 5. Lexical expand только при дырке

Сначала hybrid+rerank в `search_context`. Lexical (`kb_expand`) — только если
запрос просит контракт, а в RAG ещё нет JSON/таблицы полей; lexical идёт после
RAG, с жёстким cap. FE-скоринг под tax/cancel — вынести в конфиг или снять после
A/B, когда Qdrant+rerank стабильно попадают в нужный файл.

## 6. Доменный слой снаружи ядра

ASR-синонимы и glossary (LinkedIn → Linked Events, вармаржа, TAX_RETAIN и т.п.) —
опциональная обёртка, не часть универсального retrieve.

## 7. Eval не на трёх любимых промптах

Набор сценариев: новый тип операции, новый обмен, FE vs BE, follow-up без сырой
истории в answer. Иначе снова натащим доменные костыли под то, что проверяли руками.

---

**Сжатый тезис:** универсальность = правильные чанки и метаданные + общий retrieve;
доменные словари — только обёртка. Реранкер нужен, но один он мега-секции и
доменные if’ы не заменит.
